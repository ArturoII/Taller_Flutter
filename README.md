# Taller Flutter - Navegación y Ciclo de Vida

## Descripción

Esta aplicación Flutter es parte de un taller que muestra el uso de:

- Navegación entre pantallas usando `Navigator`.
- Paso de parámetros entre pantallas.
- Ciclo de vida de un `StatefulWidget` con uso de `print()`.
- Widgets como `GridView`, `TabBar`, `Switch` y `Slider`.

## Cómo correr el proyecto

1. Clona el repositorio o descarga el proyecto.
2. Asegúrate de tener Flutter instalado y actualizado.
3. En la raíz del proyecto, ejecuta:

```bash
flutter pub get
flutter run
